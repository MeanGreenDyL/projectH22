# Project H 2:2

> "Write the vision, and make it plain upon tables, that he may run that readeth it."
> — Habakkuk 2:2 (KJV, public domain)

A research-grade, visual-first platform documenting real-world events in cybersecurity,
cryptocurrency markets, US law and global geopolitics, alongside clearly-labelled, self-critical
scholarly correlations with biblical text including the Apocrypha.

Facts and interpretation are separate data models with separate validators. Every correlation
carries its strongest counter-argument, and scripture-derived scenarios never carry dates.

**Status:** Phase 0 (scaffold and contracts). No UI or content yet. See `docs/PHASE-0-PLAN.md`.

## Quick start

```
pnpm install
pnpm gate        # validate + validate:credibility + tests
```
